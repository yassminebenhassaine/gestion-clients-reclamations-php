# Gestion des Clients et Réclamations

Application web développée en PHP pour la gestion des clients et de leurs réclamations.

## 🛠️ Technologies
- PHP
- MySQL
- HTML / CSS / JavaScript

## 🚀 Installation
1. Copier le projet dans `xampp/htdocs/`.
2. Importer la base de données MySQL.
3. Démarrer Apache et MySQL sur XAMPP.
